# Support

Use [GitHub issues](https://github.com/tiagovilasboas/grok-bot-architecture/issues/new/choose) for reproducible validator problems, adoption questions, or documentation gaps. Include the commit, Node.js version, redacted input, expected behavior, and actual result.

Describe workloads with fictional resources. Do not share private accounts, customer names, workspace dumps, or message histories. Security concerns follow [SECURITY.md](SECURITY.md).

Help is community-based with no guaranteed response time. Contributions follow [CONTRIBUTING.md](CONTRIBUTING.md).
