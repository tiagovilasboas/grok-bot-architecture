# Security policy

This repository supplies reference contracts and local validators. It is not an authorization service. Read [host integration](docs/host-integration.md) and [security design](docs/security.md).

## Report a concern

Do not publish secrets, personal data, private transcripts, or sensitive exploit details in a public issue. Use GitHub **Security → Report a vulnerability** if that entry is available. If private reporting is unavailable, request a private reporting channel in a minimal issue without sensitive details. No response-time SLA is promised.

Include the reviewed commit, affected file, redacted reproduction, expected and actual behavior, and impact.

## Maintenance scope

The default branch is the maintained reference. Tagged releases have no separate security-support commitment unless documented. Validator success does not establish authenticated approval or production security.
